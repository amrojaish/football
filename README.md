## ⚠️ دروس تقنية حاسمة

اكتُشفت بالتجربة وكلّفت وقتاً. لا تُنسَ.

### 1. حد الطلبات بالدقيقة
الخطة المجانية ~10 طلبات/دقيقة (غير معلن). تجاوزه يُرجع **رد 200
بمصفوفة فاضية بدون رسالة خطأ** — يبدو كأنه "لا توجد بيانات".
- مجاني: `DELAY = 7.0`
- Pro: `DELAY = 1.0` (مُختبر ويعمل)

### 2. الفشل الصامت — أخطر نمط
```python
return r.json().get("response", [])   # يبتلع كل الأخطاء
```
هذا السطر جعلنا نظن أن الـAPI لا يملك أحداثاً للدوريات العربية،
وكدنا نلغي فكرة المشروع كلها. **أي دالة تجلب بيانات يجب أن تفحص
الأخطاء وترجعها، لا أن تخفيها.**

### 3. Missed Penalty ليست هدفاً
الـAPI يصنّفها `type = "Goal"`. يجب استثناؤها بالسحب وبالعرض:
```python
if e.get("detail") == "Missed Penalty": continue
```

### 4. أهداف ملغاة بمباريات 0-0
تظهر بجدول الأحداث ولا تدخل بالنتيجة (تسلل/VAR)، وغالباً بلا اسم
لاعب. يعالجها `fix_goals.py`.

### 5. الفلاتر الناقصة
كل استعلام يحتاج `league_code AND season`. نقص أحدهما يخلط البيانات
بصمت. ظهرت المشكلة مرتين (الدوري ثم الموسم).

### 6. INNER JOIN يحذف بصمت
الأندية غير الموجودة بجدول `teams` **تختفي من النتائج بلا تحذير**.
ظهر جدول ترتيب بـ8 فرق بدل 10 لهذا السبب.

### 7. الشبكة غير موثوقة
انقطاعة واحدة كانت تُسقط سحب 374 مباراة. الحل: `try/except` +
إعادة محاولة بتأخير متزايد + تخطي الفاشل بدل الانهيار.

### 8. الدمج لا الاستبدال
أي سكربت يلمس ملفاً فيه شغل يدوي يجب أن **يدمج**. الاستبدال يمحو
ساعات عمل بصمت. (`update_teams.py`, `export_players.py`)

### 9. مسار الداتا
```
teams_arabic.csv -> [sync_teams.py] -> football.db -> [make_site3.py] -> site.html
```
التعديل بالمصدر **لا يصل للنهاية وحده**. أي تعديل على الـCSV يحتاج
`sync_teams.py` بعده.

### 10. اختبار اكتمال الموسم
```
عدد المباريات = (مباريات كل فريق × عدد الأندية) ÷ 2
```

| الدوري | موسم | أندية | متوقع |
|---|---|---|---|
| JOR | 2024 | 12 | 132 |
| JOR | 2025 | 10 | 135 (نظام 3 مراحل، 27 مباراة) |
| IRQ | 2025 | 21 | 420 (عندنا 374 — الموسم قد لا يكون منتهياً) |

### أعمدة teams_arabic.csv
```
league_code | league_ar | team_id | name_en | name_ar
short_name_ar | city | logo | logo_local | logo_note
```

### جداول football.db
```sql
teams   (team_id, league_code, name_en, name_ar,
         short_name_ar, city, logo)
matches (match_id, league_code, season, date,
         home_id, away_id, home_goals, away_goals, status)
goals   (id, match_id, team_id, minute,
         player_en, player_ar, detail)
```
عمود `player_ar` **فارغ** — هذا هو العمل القادم.

## مبادئ متفق عليها

1. **التحقق قبل البناء** — لا يُكتب كود قبل إثبات توفر الداتا
2. **الأصول اليدوية هي الميزة** — الأسماء والشعارات المصححة لا تُنسخ بسهولة
3. **فصل البيانات عن المنطق** — الكود يعرف *كيف*، والداتا تقول *ماذا*
4. **الديتابيس المحلية أولاً** — العمل على الداتا لا يستهلك الحصة
5. **توثيق التصحيحات لا محوها** — عمود `logo_note` سجل شفاف
6. **أي نتيجة مخالفة للتوقع تستحق تفسيراً** — حتى لو بدت إيجابية.
   الشذوذ الصغير المُهمَل أخفى أكبر باگ بالمشروع.
